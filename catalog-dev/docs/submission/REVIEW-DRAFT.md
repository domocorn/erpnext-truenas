## Description

Adds single-site ERPNext to the community train using the TrueNAS 2.3.17 library for storage permissions, MariaDB, ports and portals. Includes Redis cache/queue, backend, frontend, websocket, workers and scheduler, with digest-pinned images.

The native lifecycle records site/image identity and holds shared runtime locks versus exclusive initialization/backup/migration locks. Upgrades stop the old application, back up with its original image, then migrate with the target image. Persistent operation state blocks runtime after an incomplete migration. Queue checks refuse pending or failed work without clearing it; workers receive a 120-second warm-stop grace period. Only the reviewed ERPNext 16.51.1 -> 16.52.1 digest pair is enabled.
